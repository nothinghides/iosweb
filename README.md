# D.A.R.S. for iPhone & iPad

A Web Bluetooth Remote ID viewer for D.A.R.S. receivers. iPhone/iPad users open
this page in the free **Bluefy** Web‑BLE browser (Safari can't do Bluetooth); it
also works in Android Chrome. It only functions with a genuine, licensed D.A.R.S.
device.

**Live page:** enable GitHub Pages (Settings → Pages → deploy from branch, root),
then open the resulting `https://…github.io/…` URL in Bluefy.

Built/obfuscated single file — source lives in the private D.A.R.S. project.
